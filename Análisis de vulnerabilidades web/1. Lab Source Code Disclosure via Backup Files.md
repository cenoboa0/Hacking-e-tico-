### Fase 3 — Análisis de Código Fuente y Exfiltración

Tras descargar `ProductTemplate.java.bak` y auditar el código fuente de la clase Java, se localizaron credenciales hardcodeadas dentro del método de deserialización `readObject()`:

```java
// Fragmento identificado en ProductTemplate.java.bak
// Método: readObject() — Conexión a base de datos PostgreSQL

String driver   = "org.postgresql.Driver";
String url      = "jdbc:postgresql://localhost:5432/postgres";
String username = "postgres";
String password = "2ompi1an8ogbv8xcj2maspgcjoy5qqdx";  // ← CREDENCIAL EXPUESTA
```

## 4. Impacto del Riesgo

Un atacante que obtenga estas credenciales podría:

- 🔑 **Acceso no autorizado** a la base de datos (directamente si el puerto `5432` estuviera expuesto, o mediante técnicas de pivotaje como SSRF/RCE).
- 📤 **Exfiltración de datos confidenciales** — clientes, productos, información corporativa *(Violación de Confidencialidad)*.
- ✏️ **Modificación o eliminación arbitraria** de registros *(Pérdida de Integridad y Disponibilidad)*.

---

## 5. Recomendaciones de Mitigación

### ✅ Eliminar Archivos No Utilizados
Implementar políticas de limpieza estrictas en servidores de producción. No deben desplegarse:
- Archivos temporales: `.swp`, `~`
- Respaldos: `.bak`, `.old`
- Código fuente sin compilar: `.java`

### ✅ Deshabilitar el Directory Listing
Configurar el servidor web para devolver `403 Forbidden` en lugar de listar el contenido de carpetas cuando no existe un archivo de índice (`index.html` o similar).

```apache
# Apache — deshabilitar Directory Listing
Options -Indexes
```

```nginx
# Nginx — deshabilitar Directory Listing
autoindex off;
```

### ✅ Externalizar Credenciales (Variables de Entorno)
**Nunca escribir contraseñas hardcoded en el código fuente.** Las credenciales deben gestionarse mediante:

- Variables de entorno del sistema operativo.
- Almacenes de secretos dedicados: [HashiCorp Vault](https://www.vaultproject.io/), [AWS Secrets Manager](https://aws.amazon.com/secrets-manager/), [Azure Key Vault](https://azure.microsoft.com/en-us/products/key-vault).

```java
// ❌ MAL — Credencial hardcodeada
String password = "2ompi1an8ogbv8xcj2maspgcjoy5qqdx";

// ✅ BIEN — Credencial desde variable de entorno
String password = System.getenv("DB_PASSWORD");
```

### ✅ Restringir el uso de `robots.txt`
`robots.txt` **no es un mecanismo de seguridad** — cualquier usuario puede leerlo. Rutas sensibles no deben listarse allí si están expuestas al público.
