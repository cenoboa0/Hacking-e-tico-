
# Informe de Vulnerabilidad: Divulgación de Código Fuente mediante Archivos de Respaldo

## 1. Resumen Ejecutivo

* **Nombre de la Vulnerabilidad:** Divulgación de Código Fuente mediante Archivos de Respaldo (*Source Code Disclosure via Backup Files*).
* **Severidad:** **Alta** (Debido a la exposición directa de credenciales administrativas con acceso total a la base de datos).
* **Descripción Corta:** Se identificó un archivo de copia de seguridad expuesto públicamente en el servidor web. El análisis estático de dicho archivo reveló credenciales de conexión fuertemente integradas en el código (*hardcoded*) que permiten el acceso sin restricciones a la base de datos de producción.

---

## 2. Detalles de la Vulnerabilidad y Alcance

* **URL Afectada:** `https://0a1d001a0385e41d8164432e005e0026.web-security-academy.net`
* **Componente Crítico:** Archivo expuesto en `/backup/ProductTemplate.java.bak`
* **Debilidad CWE:** [CWE-530: Exposure of Modification History, Repository, or Backup Files](https://cwe.mitre.org/data/definitions/530.html)

---
